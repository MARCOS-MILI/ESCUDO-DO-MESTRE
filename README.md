# Escudo do Mestre

Site só do mestre pra Sessão das Oito (Ordem Paranormal RPG 2, Coxilha Seca, 1978). Abre no celular, sem login, sem banco de dados.

Endereço: https://marcos-mili.github.io/ESCUDO-DO-MESTRE/ (GitHub Pages, branch `main`, pasta raiz).

Abas: Mesa, Regras, Dados, NPCs, Enigmas, Jogadores, Mapas, Links, Notas.

## Arquivos

- `index.html`, `style.css`: a página e o visual.
- `app.js`: abas, rolador, filtros, links e notas.
- `dados.js`: a conta dos dados (escada, crítico, pavor, chance exata).
- `data.js`: o texto da mesa (regras, cenas, rádio, enigmas, jogadores, mapas, lugares). Mudar texto é aqui.
- `npcs.js`: os NPCs.
- `img/`: cartões de NPC, peças e mapas (WebP; o `-t` no fim é a miniatura).

## Imagens pros jogadores

Os botões "Copiar link" da aba Links (e dos mapas dos jogadores) montam o link no **site dos jogadores**
(`sessao-das-oito/pecas/`), não neste site. Assim nenhum link que vai pra mesa entrega o endereço do Escudo.
Se uma peça nova for pros jogadores, ela precisa estar nas duas pastas: `img/pecas/` aqui (pra ver no Escudo)
e `pecas/` no repositório `sessao-das-oito` (pro link funcionar).

## Aviso

O repositório é público. Quem achar o endereço enxerga tudo, inclusive os cartões dos NPCs e as respostas dos enigmas.
Não mande o endereço deste site pros jogadores.

As anotações, o PV dos NPCs, as cenas marcadas e os códigos das fichas ficam salvos só no aparelho onde você usou.
Na aba Notas tem backup pra copiar e restaurar.
