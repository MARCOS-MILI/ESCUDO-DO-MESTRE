# Escudo do Mestre

Site só do mestre pra Sessão das Oito (Ordem Paranormal RPG 2, Coxilha Seca, 1978). Abre no celular, sem login, sem banco de dados.

Abas: Mesa, Regras, Dados, NPCs, Enigmas, Jogadores, Mapas, Links, Notas.

## Pôr no ar (GitHub Pages)

1. No GitHub, criar o repositório `escudo-do-mestre` (público, o Pages grátis pede isso).
2. Subir todo o conteúdo desta pasta (index.html, style.css, app.js, dados.js, data.js, npcs.js, a pasta img/ e este README).
3. Em Settings > Pages, escolher Deploy from a branch, branch `main`, pasta `/ (root)`. Esperar uns 2 minutos.
4. O endereço fica https://marcos-mili.github.io/escudo-do-mestre/ (é o que a aba Links usa pras imagens dos jogadores).

## Aviso

O repositório é público. Quem achar o endereço enxerga tudo, inclusive os cartões dos NPCs e as respostas dos enigmas. Não mande o endereço do site pros jogadores. Mande só os links das imagens da aba Links.

As anotações, o PV dos NPCs, as cenas marcadas e os códigos das fichas ficam salvos só no aparelho onde você usou. Na aba Notas tem backup pra copiar e restaurar.
